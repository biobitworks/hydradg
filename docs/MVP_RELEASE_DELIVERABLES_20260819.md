# HydraDG MVP release deliverables — 2026-08-19

## Must-have public artifacts

1. Overview page — simple value proposition and golden path.
2. Demo page — submission landing page + video slot.
3. Results/Evidence — executed, negative/null, pending and blocked states.
4. Experiments — Track 01, 02 and 03 pages.
5. Graph Explorer — deep technical graph view.
6. Knowledge — project-term → FCG → source resolution.
7. Eligibility — build-window and release custody.
8. Static fallback — backend-independent judge artifact.
9. Fresh public repository export.
10. <=3-minute video.

## Must-have execution artifacts

- current local release batch receipt;
- Track 03 fresh poison/antidote golden-path receipt;
- Track 01 synthetic canary receipt or explicit pending state;
- Track 02 synthetic canary receipt or explicit pending state;
- dataset acquisition receipts;
- full500 result/statistics/receipt identities;
- artifact SHA-256 manifest;
- secret scan result;
- public link audit.

## Nice-to-have only after must-have gates

- hosted HydraDB cloud conformance;
- full EnterpriseRAG/HERB benchmark scaling;
- BEAM-10M;
- physical/thermodynamic interpretation of information metrics;
- additional UI animations;
- additional track-specific schemas beyond the bounded demonstrations.

The MVP should not delay submission for a nice-to-have item.
