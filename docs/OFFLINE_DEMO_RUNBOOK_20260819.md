# Offline demo runbook — 2026-08-19

Use this only when the live release URL is unavailable or not promoted to the current release branch.

## Open locally

```bash
open apps/hydradg-web/public/backup/hydradg.html
```

or serve the repository locally:

```bash
python3 -m http.server 8088 --directory apps/hydradg-web/public
```

Then open:

```text
http://127.0.0.1:8088/backup/hydradg.html
```

## Video sequence

1. Show the fallback hero and one-sentence problem.
2. Scroll through reference → poison → antidote.
3. State the completed full500 negative/neutral result.
4. Switch to the local Judge Lab only if the local HydraDB stack is green; clearly label it local execution.
5. Show Results/Evidence or retained receipts/hashes.
6. End with the public repository/source instructions.

The static page is not evidence that local HydraDB is running. It is a presentation artifact linked to separately executed evidence.
