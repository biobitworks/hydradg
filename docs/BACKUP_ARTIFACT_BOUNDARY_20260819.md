# Backup artifact boundary — 2026-08-19

The static fallback is intentionally bounded:

```text
CAN PRESENT
- problem and architecture
- recorded executed result identities
- track descriptions
- claim ceilings
- release/status explanation

CANNOT CLAIM BY ITSELF
- live HydraDB execution
- current cloud availability
- successful perturbation receipt
- project signature
- live Merkle/MMR commitment
- independent replication
```

Its evidence class is a deterministic presentation transformation of retained project statements and should remain linked to the underlying evidence objects rather than being treated as new empirical evidence.
