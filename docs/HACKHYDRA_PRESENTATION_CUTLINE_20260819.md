# Hack Hydra presentation cut line — 2026-08-19

The project should stop adding public-facing conceptual surfaces after:

```text
Overview
Demo
Results
Experiments
Graph Explorer
Knowledge
Eligibility
Static fallback
```

New technical capabilities should be linked beneath one of these surfaces rather than creating another primary navigation item unless the hackathon requirements explicitly demand it.

This keeps the judge path simple while allowing arbitrary depth through the FCG/knowledge graph.
