# Demo Golden Path — HydraDG @ Agent Native Builders Hackathon

## Overview
HydraDG provides multi-agent handoff custody, deterministic evidence linking, and FCO/FCG provenance for autonomous AI engineering teams.

## Hackathon Golden Path Scenario (23-Hour Build Schedule)

### Day 1: Multi-Agent Handoff Custody Node & MCP Bridge
1. **09:00 - 12:00:** Deploy real-time FCO/FCG custody verification service for agent tool calls.
2. **12:00 - 16:00:** Wire MCP endpoints (`ic_endpoint_register`, `ic_rooms_*`) for real-time agent turn receipts.
3. **16:00 - 20:30:** Validate deterministic SHA-256 hashing across multi-model handoffs (Antigravity/Gemini <-> Claude <-> Ollama).

### Day 2: Live Verification & Judging Submission
1. **09:00 - 14:00:** Run end-to-end autonomous research and code transformation workload with live custody receipts.
2. **14:00 - 17:00:** Generate audit graph visualization and package submission repository.
3. **17:00 - 20:30:** Present live demonstration to judges against the Agent Native rubric.
