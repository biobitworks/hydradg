**Title:** HydraDG: Governed Context Interventions with Fractal Custody for Agent Experiments

**Keywords:** agent evaluation, scientific custody, preregistration, failure preservation, structured retrieval, reproducibility, LLM agents

**TLDR:** HydraDG binds agent experiments to hash-linked custody receipts; preregistered EXP-008/009 close underpowered, preserving null and failure cells rather than promoting structured-retrieval effects.

**Abstract:** Agent evaluations increasingly depend on context interventions---retrieval, memory graphs, and prompt contracts---yet published reports often omit null outcomes, parser failures, and negative cells. We present HydraDG, a governed experimental framework that binds substantive model invocations, tool calls, and handoffs to \emph{Fractal Custody Objects} (FCOs) and a \emph{Fractal Custody Graph} (FCG). HydraDG preregisters hypotheses, freezes case manifests and scorers, records raw prompt and response hashes, and preserves terminal states including timeouts, abstentions, and malformed outputs without silent substitution. We report two preregistered studies (EXP-008, EXP-009) comparing flat prose versus structured FCG retrieval for failure-prevention endpoints; both terminate as \emph{underpowered} under bounded case replication, so confirmatory effect claims are not supported while negative and null evidence remains in custody. We argue that custody-first evaluation infrastructure supports reproducible agent science rather than optional logging.
