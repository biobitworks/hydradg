# FCG update gate — 2026-08-19

The project FCG update is considered documented when:

- reason for expansion is written;
- machine-readable changelog exists;
- live/static artifacts are represented as distinct delivery objects;
- website knowledge-link contract is defined;
- artifact hashing procedure exists;
- signing state remains explicit;
- updated artifacts are included in the fresh public export.

Execution of the hash manifest and public export remain separate gates.
