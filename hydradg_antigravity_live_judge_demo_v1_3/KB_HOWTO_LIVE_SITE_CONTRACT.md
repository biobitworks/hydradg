# KB + How-To Live Site Contract v1

Antigravity must add the following repository and live-site surfaces.

## Repository docs

Add or update:
- `docs/KNOWLEDGE_BASE_GUIDE.md`
- `docs/HOW_TO_USE_HYDRADG.md`

## Live routes

Preferred:
- `/knowledge`
- `/how-to`

If `/how-to` is not desirable, include a clearly visible `How to Use` section within `/knowledge`,
but a dedicated route is preferred for the judge demo.

## Persistent navigation

Update live navigation to:

`Overview | Judge Demo | Results | Graph | Knowledge | How to Use | Eligibility | Static Fallback`

## Required CTA links

- Overview: `How this works`
- Judge Demo: `Need a term? Open Knowledge Base`
- Track 03: `How to read these metrics`
- Graph: `How to trace an FCO`
- FCO detail: `Open Knowledge Base`
- Eligibility: `How to interpret custody states`
- Static fallback: `Return to Live Demo`

## Search / index

The Knowledge page should allow fast lookup of declared project terms.
A lightweight client-side filter is sufficient for tonight.

## Judge-safe content

The KB must clearly distinguish:
- architecture terms;
- metrics;
- claim ceilings;
- custody state;
- experimental results;
- application-level knowledge FCOs.
