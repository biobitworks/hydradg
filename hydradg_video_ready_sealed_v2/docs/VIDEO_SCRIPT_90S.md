# 90-second HydraDG local-private demo

## 0–10s
Homepage.
"HydraDG is a governed context graph running locally on one Mac: the site, HydraDB state,
custody graph and local model inference are all local."

## 10–28s
Rotate/scrub the Context Iceberg.
"Instead of a linear status bar, this is a context field. The graph changes over time.
Cloud width shows frozen distributional drift and hue shows the direction of our
dimensionless delta-G abstraction. Accuracy and recall remain separate."

## 28–48s
Evidence / Track 03.
"The first full benchmark did not show a positive graph-retrieval advantage at K5, and we
kept that result. We then changed one variable at a time and tested deeper retrieval."

## 48–66s
Model comparison.
"Two approved local seven-billion-parameter models saw the same frozen diagnostic packet
and predicted before the held-out K15 run. Both predicted lower delta-G. K15 moved in that
direction, but neither model beat the other, so the decision remains
NO_PROMOTED_MODEL_DIFFERENCE."

## 66–80s
Custody graph.
"Every source, transformation, benchmark result and model output is retained with hashes
and claim ceilings. HydraDB is the query projection; the custody graph remains the evidence spine."

If signature pending:
"The artifacts are hashed; the external Ed25519 signature is still pending."

## 80–90s
Return to hero.
"The point is not to manufacture a win. HydraDG shows what changed, what stayed null,
what the models predicted, and where every claim came from—locally and privately."
